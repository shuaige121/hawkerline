# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** (Security → Advisories) on this repository rather than in a public issue. Include the affected route or file, steps to reproduce and the impact you observed.

Operators: keep `ADMIN_TOKEN`, `AUTH_SECRET` and agent keys out of chats, screenshots and source control. Revoke an agent key in `/admin` → 🤖 AI 接入 as soon as it may have leaked.
