许可常见问题

Hawkerline 免费吗？

餐饮商户若连同关联方在上一财年的年营业额不超过 1,000 万新元，可免费用于自家门店。个人、评估、教学与非商业用途同样允许。

可以请 IT 承包商替我部署吗？

可以。符合条件的商户可以安装、修改、自行托管，也可以请 IT 承包商为商户自己的使用进行部署。

系统商或代理商不能做什么？

未取得单独的商业许可前，系统商、POS 或 SaaS 服务商、代理商与集成商不得销售、转售、转授权、作为服务替其他商户托管，或将其打包进商业产品。

年营业额超过 1,000 万新元怎么办？

超过该门槛的商户须取得商业许可。请在 GitHub 仓库 提交 issue，联系许可方。

Hawkerline 是开源软件吗？

它是源码公开，不是 OSI 意义上的开源。你可以在 Hawkerline Community License 的条款内阅读和修改源码。

年营业额如何计算？

按商户连同其关联方在上一财年的营业额计算，门槛为 1,000 万新元或以下。

IT 承包商可以向我收取部署费用吗？

可以。承包商可以收费为某一家符合条件的商户部署 Hawkerline，但不得销售软件，也不得用同一个部署同时为多家商户运行。

业务增长超过 1,000 万新元怎么办？

超过门槛后有 90 天时间取得商业许可。请在 GitHub 仓库 提交 issue，联系许可方。

许可方是谁？

Leonard Chow Yi Ding。许可文件为 LICENSE（Hawkerline Community License 1.0）。

有担保或支持合同吗？

没有。Hawkerline 按现状提供，不附带担保。
